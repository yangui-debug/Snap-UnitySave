# 右桥近战推拉

## 配置位置

场景：`Assets/20261012-PVE守关敌万军/20261012-PVE收关敌万军.unity`。

在层级中选择 **蓝木盾卫士**，调整 `RightBridgeMeleeDirector`。所有新增可调参数均在此组件集中公开，并带中文 Tooltip。

组件通过根节点引用识别木盾兵，通过世界交战区、场景和阵营识别进入右桥的红方近战。远程不接入；退出右桥区域的单位退出新增控制。特别是 Timeline 在约 14 秒后向左移动的后排盾兵，离开右桥后仍按原 Timeline 行进。

`RightBridgeMeleeUnit` 是运行时安装的单兵仲裁器，不需要逐个添加或修改共享兵种预制体。

## 行为

- 伤害来源由攻击事件/箭矢端明确传入。原 `TakeDamage(int, Vector3, bool)` 签名保留，未指定来源走原闪白设置。
- 近战闪白默认 0.08 秒、原自发光强度的 25%。远程默认保持原参数。关闭对应闪白不取消伤害、击退、死亡、缩放或独立加速闪红。
- 受击保持角色原击退距离、时长、轴向和僵直设置，由仲裁器执行；原受击协程继续处理动画、材质、缩放和已有 Timeline 暂停逻辑。位移不再由协程和 Rigidbody 同时执行。
- 红方常规寻路继续负责原过桥、路径和目标选择；最终移动速度由仲裁器处理。击退和僵直期间寻路输出让位，结束后按当前目标重新更新路径。
- 后排不会主动进入前排的退让净空间。同一阵营多个单位不能同时预留同一接战位置。等待期间不关闭原攻击条件，因此有合法攻击目标时仍可攻击。
- 蓝方只沿配置的世界战线轴跟进，以首次接战位置记录固定基准；前进 1.5 单位、后退 1 单位为默认边界，跟进速度 1.6 单位/秒。新增跟进停止距离默认为 1.1 单位，并叠加原有每人固定站位差异；碰撞不足时会提前停止，不会为达到此距离穿过敌人。
- 红方从被友军阻挡状态恢复，或旧接战目标死亡后，在前路可用、存在有效目标的条件下独立等待 0.18～0.55 秒再补位。再次阻挡、目标变化、目标失效会重新判断，不向旧空位盲冲。
- 物理扫掠和落点重叠检查限制跟进/击退位移；空间不足时允许击退变短。重力和物理碰撞继续由原 Rigidbody 处理。
- 死亡/失活单位立即失去占位权。死亡替身生成与表现不改动。

## 开关与调节

关闭管理器的 `enablePushPull` 后，新增移动仲裁、按来源闪白、等候、跟进和补位控制均退出；不瞬移回旧站位。未指定来源的伤害、左桥及其他场景继续走原代码。

`enableShieldFollow`、`enableQueueSpacing`、`enableHitMovementPriority`、`enableRedRefillDelay` 为独立行为开关。近战/远程闪白各有独立开关。

前排退路默认 2 单位，另加双方水平半径。若后排本来已经拥挤，系统只禁止继续挤入，不将后排瞬移移开。建议结合实际队列间距调节。

`minimumFrontSeparation` 默认 0.6 单位，避免斜列同排邻兵因为领先几厘米被误判成前排。未启用的旧控制器不进入占位表。盾兵有独立刚体时使用对应单兵物理根；本场景已移除刚体的盾兵使用 Animator 外的单兵容器，避免动画将模型位置写回。两种情况均禁止提升到共享 Timeline 编组节点。

选中管理器查看绿色交战区和青色前后轴。播放时选中单兵可查看固定边界、黄色退让空间和紫色预留位置。范围随对应功能开关显隐。

## 验收工具

Unity 菜单：**Tools → 右桥近战 → 运行45秒实际场景验收**。

工具只在目标场景单独打开、无未保存场景、当前未播放时启动。不会保存场景。结果写入 `Temp/RightBridgeValidation.json`，包括接入人数、受击/等候观察人数、盾兵前后位移、越界情况、移动阻挡原因和运行错误。工具退出自己启动的播放后恢复临时后台运行和日志堆栈配置。

需要人工复核：前排的实际后退幅度、后排退路、双方攻击接触感、Timeline 后期调队表现、近战闪白舒适度。数值采样和编译通过不能代替这些视觉验收。

建议对比场景：持续密集接战、前排死亡连续补位、连续受击、队列拥堵、敌人离开交战区、开关关闭、Timeline 后排转向左侧。保留现有伤害、范围、箭矢、生成、死亡和血条参数。
